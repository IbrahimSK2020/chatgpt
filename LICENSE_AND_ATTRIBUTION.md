# Attribution and reuse note

This package is a small derived curation of selected fields and functional assay values displayed by the NCI TP53 Database and a secondary evidence summary from ClinVar. The task-facing package includes source links and access dates.

Do not assume every upstream source has identical redistribution terms. Before public scientific release, check the current NCI TP53 Database and ClinVar terms, provide required attribution, and document any constraints. This pilot is intended for research and benchmark development, not clinical decision-making.

No clinical diagnosis, clinical pathogenicity classification, or patient-specific medical advice is provided.
